# Flashcard App

My first project in TripleTen's AI-Assisted Software Engineering program.

FlashCards is a web-based study application that helps students review coding concepts with digital flashcard decks. Users can browse preset decks, open a deck to view its cards, flip cards to reveal answers, delete decks or cards, and practice cards in a carousel view.

## Features 
- Browse flashcard decks loaded from a remote database
- Open a deck to view its flashcards
- Flip flashcards to see questions and answers
- Create new decks by pasting deck JSON
- Delete decks or individual flashcards with a confirmation modal
- See validation and API errors in a modal
- Practice a deck in a carousel view
- View an About page with an example JSON deck format
- Responsive layout for desktop and mobile screens
- JavaScript functions documented with JSDoc

## Technologies used
- HTML
- CSS
- JavaScript
- TripleTen Flashcards API
